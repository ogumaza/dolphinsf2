A release that follows the game more closely. Release tails keep their settings. Notes whose envelope falls to silence fade out when they're released. Every note is kept by default. Convert a game again to get the corrected files.

Requires 64-bit Windows 10 or later, with no additional runtime DLLs. The executable is now built with clang-cl instead of MSVC. Drop a game's disc image or its `.baa` file onto `dolphinsf2.exe`. You can also use a terminal. `dolphinsf2 --help` lists the options. Output goes in a folder beside each input.

For macOS on Apple Silicon, follow the build instructions in the README. Linux and Intel Macs are no longer supported. macOS builds include `Dolphinsf2.app`. Drop inputs onto the app in Finder to convert them.

## New

- **Every note is kept by default.** 1.0.0 always played with the game's 64 voices and cut the notes that lost their voice. `--voices N` plays with N voices and drops the notes that the game drops when every voice is busy. The result only approximates the game. `--voices off` keeps every note. That's the default.
- **Twilight Princess** converts. 1.0.0 stopped at its start-up archive with "archive has a chunk of unknown kind". The game compresses its sequence archive with Yaz0. dolphinsf2 decodes that archive. dolphinsf2 leaves out the sounds that play streamed audio files. The game isn't on the README's list of games known to work.

## Fixes

- **Release tails keep their settings.** A track that changes its volume, pan, pitch or another setting while its released notes still sound moves to another MIDI channel. The released notes keep the settings they had, as in the game. They used to take the track's later changes. A track that still holds a note on the channel stays there. The report lists that as an approximation.
- **Notes whose envelope falls to silence or stops** fade out on release in the SoundFont and SFZ files, as in the game. Their release is fitted from the envelope's peak. They used to stop at once.
- **Loops.** A player that loops on the loopStart marker or on CC111 repeats each pass at the tempo of the loop's start. The tempo changes on the loop's first tick now come after the marker and CC111. Playback without looping is the same.
- **Banks whose chunks run past their stated size** load. Sounds on those banks used to come out without their notes. The Japanese release of Four Swords Adventures has one such bank. Twilight Princess has two.
- **Note-offs after the end.** A note released in a tick that runs after the end of the last pass keeps its note-off. This can happen in fast sequences.
- **Memory errors.** dolphinsf2 no longer reads freed memory when a track opens another track while one of its notes plays the track's envelope. dolphinsf2 also no longer reads past an envelope's end when a track switches a playing note to a shorter envelope.
- **macOS's "._" files.** macOS writes a "._" file beside each file that it copies to a FAT or exFAT drive. The one beside the sequence archive no longer stops the game's music from converting.

## Damaged files

- A file with a WDF header that also holds the GameCube's disc signature at offset 0x1C reads as a WDF image. 1.0.0 read it as a GameCube disc. No real WDF file has the signature there.

## Known limitations

- dolphinsf2 doesn't apply the envelope scale that command 0xe7 sets. Twilight Princess uses the command in some sound effects.
- The rest are as in 1.0.0, apart from the fixes above. See "Differences from the game" in the README for the full list.
