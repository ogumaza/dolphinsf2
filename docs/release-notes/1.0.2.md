A release that follows Four Swords Adventures more closely. System sounds now play at the game's level. Notes without a release fade out as in the game. Sounds that send to the game's echo end when the echo falls silent. In every game, overlapping notes of the same key keep their MIDI channels. Convert a game again to get the corrected files.

Requires 64-bit Windows 10 or later. No additional runtime DLLs are required. Drop a game's disc image or its `.baa` file onto `dolphinsf2.exe`. You can also use a terminal. `dolphinsf2 --help` lists the options. Output goes in a folder beside each input.

For macOS on Apple Silicon, follow the build instructions in the README. macOS builds include `Dolphinsf2.app`. Drop inputs onto the app in Finder to convert them.

## New

- **Game rules.** Some rules for a game's sounds are in the game's code. The game's files don't hold them. dolphinsf2 now recognizes a game by its start-up archive. dolphinsf2 then follows the game's rules. Four Swords Adventures has rules for its system sounds' volume, for notes without a release and for its echo. The rules hold for the game's USA and Japanese releases.

## Fixes

- **System sounds.** Four Swords Adventures plays its system sounds, the sound table's first group, at 0.7 of their volume. The game's code sets that volume. dolphinsf2 now applies it. The system sounds used to play about 3 dB too loud.
- **Notes without a release.** In Four Swords Adventures, a note whose oscillator has neither a release table nor a direct release fades out over 26.7 ms when it's released. dolphinsf2 used to stop such a note at once. That's what Twilight Princess's code does. Other games keep that rule.
- **The echo.** Four Swords Adventures sets up an echo at start-up. A sound that sends to it repeats about every 160 ms. Each repeat has half the level of the one before. MIDI and SoundFont can't describe an echo. The MIDI file of a sequence that sends to it used to end with its last dry sound. Such a file now ends when the game's echo falls silent. Looping and held sounds keep their ends.
- **Notes of the same key.** A MIDI channel can hold only one note per key. Overlapping notes of the same key take extra channels, the layers. In a sequence that used all 16 channels, such notes could go silent or end early. dolphinsf2 now keeps a channel for each layer that a part requires.

## Known limitations

- dolphinsf2 doesn't apply the envelope scale that command 0xe7 sets. Twilight Princess uses the command in some sound effects.
- The rest are as in 1.0.1, apart from the fixes above. See "Differences from the game" in the README for the full list.
